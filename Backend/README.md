# Food Delivery Management System - Backend

## Overview
The backend component is developed using Java and focuses on the business logic of the application.

## Technologies
- Java
- Object-Oriented Programming
- Java Collections
- Exception Handling

## Components
- Customer management
- Administrator operations
- Restaurant management
- Menu management
- Cart management
- Order management

## Current Status
The Java backend is developed separately and is not yet connected to the frontend or MySQL database.
