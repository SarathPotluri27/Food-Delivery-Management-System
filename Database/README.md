# Food Delivery Management System - Database

## Overview
The database component is designed using MySQL to manage food delivery information.

## Technologies
- MySQL
- SQL
- MySQL Workbench

## Database Tables
- Users
- Address
- Restaurant
- Menu_Item
- Orders
- Order_Item
- Payment
- Delivery
- Delivery_Partner

## Current Status
The MySQL database is developed separately and is not yet connected to the Java backend.
